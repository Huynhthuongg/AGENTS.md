# Architecture

Universal Project Compiler Agent is a lightweight Python application with two interfaces:

- **CLI (`upca`)** for Android/Termux-first local workflows.
- **FastAPI service** for browser use, automation, and future dashboard integrations.

## Core modules

- `planner.py` analyzes natural language requirements, infers a stack, and creates prioritized tasks.
- `compiler.py` renders a safe project scaffold from the generated plan.
- `safety.py` centralizes path validation, slug generation, markdown escaping, and secret redaction.
- `server.py` exposes health, planning, and compilation endpoints with security headers.

## Production posture

The project intentionally avoids heavyweight infrastructure by default. SQLite, Postgres, auth, and admin features can be generated by downstream projects when their requirements explicitly need them.
